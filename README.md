# 📝 Features

- ✅ Add new tasks with a title and optional description  
- 🚫 Prevent empty input submissions with validation  
- 👁️ View all added tasks  
- ❌ Delete tasks individually  
- 🧾 Tasks with descriptions supported  
- 🎨 UI styled to match the provided example  
- 💡 Bonus features:
  - Unit tests (Vitest + React Testing Library)
  - E2E tests (playwright)
  
## 🚀 Technologies Used
  **React**
  **Typescript**
  **Tailwind CSS**
  **Vitest**
  **Playwright**

## 🛠️ Setup Instructions
**Clone the repository:**
```
git clone https://github.com/Loisjersong/react-todo-list.git
cd react-todo-list
```
**Install dependencies:**
```
npm install
```

**Run the development server:**
```
npm run dev
```

**Run unit tests**
```
npm run test:ui
```

**Run E2E tests**
```
npx playwright test --ui
```
